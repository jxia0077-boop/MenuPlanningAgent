AI Recipe Generation and RAG Menu Design Agent
Built an end-to-end AI recipe generation system combining neural text generation, parameter-efficient LLM fine-tuning, retrieval-augmented generation, and automated LLM-based evaluation. Implemented GRU-based sequence-to-sequence baselines with Bahdanau attention, fine-tuned T5-small and GPT-2 using LoRA adapters, and compared model performance using BLEU-4, METEOR, and BERTScore. Developed a RAG menu-design agent over 165K+ recipes using BM25 retrieval, query rewriting, structured prompt engineering, and free-tier LLM APIs to generate multi-course menus under dietary and cultural constraints. Designed a self-evaluation and cross-evaluation LLM-as-judge framework to score generated menus on constraint satisfaction, ingredient faithfulness, culinary coherence, and bias.
